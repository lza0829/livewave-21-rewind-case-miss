# 播浪

中文名：**播浪** · 前缀 `livewave` · 端口 **6400 / 11400**

## 骨架

**互动事件入流 → 事件时间水位线推进 → 热度窗关闭发射 → 迟到修正/撤回 → 窗输出与撤回互证**

皮：直播间点赞/送礼互动。去皮是事件时间窗计算 + 允许迟到与撤回，不是直播运营后台 CRUD，不是点击会话空闲切开。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6400
# 入流 → 灌「准时热度样例」→ 水位线/热度窗 → 再灌「迟到修正样例」看撤回 → 贯验
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 互动事件 | 带事件时/处理时的点赞送礼 |
| 水位线 | 每房事件时水位 + 允许迟到秒 |
| 热度窗 | 翻滚窗；开启累计，关闭发射 |
| 撤回单 | 已关闭窗被允许迟到事件修正 |
| 旁路匣 | 超允许迟到 |
| 窗贯验 | 窗合计 ↔ 事件合计 ↔ 末次撤回 |

## 水位回退 · 回退案件（已实现 · 架构甲「未结案件封锁」）

全局口径只有一种：**变小写是「处置」，处置必须同票挂回退案件**。处置成功在同一事务内落：房间、旧水位、请求值、处置态、案件号（并挂前案号作案件上下文），同票降水位、重开窗止高于新值的已关闭窗——水位动了，已关闭窗集合必须同票跟上。同房存在**未结案件**时，新的变小写**整票拒绝**，只能先结案；不采用「案件链续裁」口径。半截失败整票回滚。

| 项 | 说明 |
| --- | --- |
| 只读审查 | `GET /api/水位变小/审查?房间键=&新值=` → 房间、旧值、新值、拒绝列表、重开列表、valid、受影响窗 |
| 处置写闸 | `POST /api/水位变小` → 同结构 + 案件号/处置态/已落盘/当前水位；拒绝或半截失败时事务整票回滚 |
| 结案 | `POST /api/回退案件/结案` → 按 房间键+案件号 双重定位结案（禁止邻房串改），结案后本房才可再处置 |
| 核证只读 | `GET /api/核证/回退案件?房间键=` → 案件簿、未结封锁、与水位闸/关窗表/热度窗的对齐核验（失齐列表） |
| 入流写闸 | 装载在 `BEGIN IMMEDIATE` 内统一经 `水位闸.守卫写水位` 推进水位（永不许变小），同事务关窗，杜绝半截 |
| 窗互证 | `水位闸.不变式`：水位≥窗止的窗不得仍开启；已关窗窗止不得高于水位 |

硬约束：禁止处置成功案件空；禁止无案件号的变小写成功；禁止邻房案件串改本房水位。

夹具 `水位回退样例`：先抬水位并关窗 → 提交变小值（处置落案、同票重开窗）→ 未结案再交更小值（整票拒绝、数值不降）→ 结案后可再处置且挂前案号。夹具 `水位回退抢锁样例`：变小写与入流并发抢锁——两边都在 `BEGIN IMMEDIATE` 内整票落盘，贯验与核证始终对齐，不得水位已动而关闭集合未跟。
