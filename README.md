# 播浪

中文名：**播浪** · 前缀 `livewave` · 端口 **6400 / 11400**

## 骨架

**互动事件入流 → 事件时间水位线推进 → 热度窗关闭发射 → 迟到修正/撤回 → 窗输出与撤回互证**

皮：直播间点赞/送礼互动。去皮是事件时间窗计算 + 允许迟到与撤回，不是直播运营后台 CRUD，不是点击会话空闲切开。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6400
# 入流 → 灌「准时热度样例」→ 水位线/热度窗 → 再灌「迟到修正样例」看撤回 → 贯验
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 互动事件 | 带事件时/处理时的点赞送礼 |
| 水位线 | 每房事件时水位 + 允许迟到秒 |
| 热度窗 | 翻滚窗；开启累计，关闭发射 |
| 撤回单 | 已关闭窗被允许迟到事件修正 |
| 旁路匣 | 超允许迟到 |
| 窗贯验 | 窗合计 ↔ 事件合计 ↔ 末次撤回 |

## 水位回退禁改（已实现 · 架构甲「禁止变小」）

全局口径只有一种：**水位事件时单调不减**。任何把水位写小的请求**整票拒绝**——水位不变、已关闭窗保持关闭、旁路界不变。不采用「受控变小并重开窗」口径。

| 项 | 说明 |
| --- | --- |
| 只读审查 | `GET /api/水位变小/审查?房间键=&新值=` → 房间、旧值、新值、拒绝列表、重开列表（甲恒空）、valid、受影响窗 |
| 写闸 | `POST /api/水位变小` → 同结构 + 已落盘/当前水位；拒绝时事务整票回滚 |
| 入流写闸 | 装载在 `BEGIN IMMEDIATE` 内统一经 `水位闸.守卫写水位` 推进水位，同事务关窗，杜绝半截 |
| 窗互证 | `水位闸.不变式`：水位≥窗止的窗不得仍开启；已关窗窗止不得高于水位 |

夹具 `水位回退样例`：先抬水位并关窗，再提交更小值——`valid=false`、水位保持旧值、已关窗仍关闭；并发提交变大水位与入流后贯验仍对齐。
